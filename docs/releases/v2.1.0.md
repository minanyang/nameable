The MCP tool `check_names` now takes `channels` or `tlds` that are empty or hold only blank entries as not given,
and uses the default instead of refusing the call. Clients that fill a tool's schema as a form, such as Glama's
inspector, send a list left blank that way, so they could not call the tool without checking domains. TLDs given
for a call that checks no domain are still refused, and the CLI is unchanged.

The Claude Code plugin's skill no longer runs the CLI through Bash when the tool is missing; it tells you the
plugin's MCP server did not start. The README now says [what Nameable sends and where](https://github.com/minanyang/nameable#what-it-sends).

## Install

```sh
npx nameable <name>
```

Requires Node.js 22 or later. To use it from an AI agent, add `npx -y nameable mcp` as an MCP server, or install the
Claude Code plugin:

```
/plugin marketplace add minanyang/claude-plugins
/plugin install nameable@minanyang
```

## 繁體中文

MCP 工具 `check_names` 現在會把空的、或只有空白項目的 `channels` 和 `tlds` 當成沒填，改用預設值，不再拒絕這次呼叫。用表單填寫工具參數的 client（例如 Glama 的 inspector）會這樣送出留白的清單，所以之前不查網域就沒辦法呼叫這個工具。在不查網域的呼叫裡填了 TLD，仍然會被拒絕；CLI 沒有變動。

Claude Code plugin 的 skill 在找不到 `check_names` 工具時，不再改用 Bash 執行 CLI，而是告訴你 plugin 的 MCP server 沒有啟動。README 也新增了[會送出哪些資料](https://github.com/minanyang/nameable/blob/main/README.zh-TW.md#會送出哪些資料)的說明。
