Nameable now checks Taiwan trademarks. The new channel `trademark-tw` looks a name up among the marks registered
with Taiwan's Intellectual Property Office (TIPO) that are in force, expired less than six months ago and so still
renewable, or applied for in the last three years. Marks are compared by the words in them, ignoring case, full-width
letters and punctuation, so `Cover-Girl` finds `COVER GIRL`.

```sh
npx nameable claude --only trademark-tw
```

A match names the mark's classes and whether it is registered, still renewable or only applied for, and links TIPO's
record of it. A mark limits a name only for goods and services like its own, so a match is a clash, not a block. A
free answer is probable: marks that look or sound alike are not checked.

TIPO's API takes about half a minute for each 5000 marks, so this project builds the list from TIPO's open data
(Open Government Data License, version 1.0) and publishes it in 16 parts; a check downloads only the part its name is
in, about 2 MB, and caches it for a day. The list leaves out who owns each mark.

`trademark-tw` is included in `--all` and in the MCP tool's default, but not in the channels picked from a project.
The Claude Code plugin's skill adds it when a project will be sold or marketed in Taiwan.

## Install

```sh
npx nameable <name>
```

Requires Node.js 22 or later. To use it from an AI agent, add `npx -y nameable mcp` as an MCP server, or install the
Claude Code plugin:

```
/plugin marketplace add minanyang/claude-plugins
/plugin install nameable@minanyang
```

## 繁體中文

Nameable 現在可以查台灣商標。新的管道 `trademark-tw` 會在經濟部智慧財產局（TIPO）的商標中查詢名稱，範圍包括：仍然有效的註冊商標、專用期限屆滿未滿六個月（仍可延展）的商標，以及近三年內提出的申請。比對的是商標圖樣中的文字，忽略大小寫、全形半形和標點，所以 `Cover-Girl` 會比對到 `COVER GIRL`。

```sh
npx nameable claude --only trademark-tw
```

查到時會列出商標的類別，以及它是已註冊、仍可延展還是只在申請中，並附上智慧局的官方紀錄連結。商標只限制和它相同或類似的商品、服務使用這個名稱，所以查到同名代表撞名，但不一定會被擋。外觀或讀音近似的商標沒有檢查，所以「可用」只能是 probable。

智慧局的 API 每 5000 筆大約要半分鐘，所以本專案從智慧局的開放資料（政府資料開放授權條款第 1 版）整理出清單，分成 16 份發佈；查詢時只下載名稱所在的那一份，大約 2 MB，並快取一天。清單不收錄商標權人。

`--all` 和 MCP 工具的預設都會查 `trademark-tw`，但從專案自動挑選的管道不會包含它。Claude Code plugin 的 skill 會在專案要在台灣銷售或推廣時加上它。
