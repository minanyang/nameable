Nameable is now on the official [MCP Registry](https://registry.modelcontextprotocol.io) as
`io.github.minanyang/nameable`, so MCP clients that browse the registry can find and install it. The npm package
names it in `mcpName`, which the registry checks; nothing else changes.

## Install

```sh
npx nameable <name>
```

Requires Node.js 22 or later. To use it from an AI agent, add `npx -y nameable mcp` as an MCP server, or install the
Claude Code plugin:

```
/plugin marketplace add minanyang/claude-plugins
/plugin install nameable@minanyang
```
