The Claude Code plugin now runs its own copy of the CLI instead of fetching it through npx. When you install or
update the plugin, Claude Code adds the CLI's two dependencies from a lockfile in the plugin, so every install gets
the same versions. The plugin needs Node.js 22 or later, as the CLI does. The plugin also has an icon; the Nameable
name and logo are not covered by the MIT License (see the
[README](https://github.com/minanyang/nameable#license)). The CLI and the MCP server are unchanged.

## Install

```sh
npx nameable <name>
```

Requires Node.js 22 or later. To use it from an AI agent, add `npx -y nameable mcp` as an MCP server, or install the
Claude Code plugin:

```
/plugin marketplace add minanyang/claude-plugins
/plugin install nameable@minanyang
```
