Nameable now depends on Zod 4.6.7, past the advisory
[GHSA-mrhx-c7xc-m3w5](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5): Zod before 4.6.6 can exhaust memory while
validating oversized constrained collections. Both the npm package and the Claude Code plugin's lockfile carry the
fixed version. Nothing else in how names are checked has changed.

The MCP tool `check_names` also declares `destructiveHint: false`, next to its other hints, for directories that
require all four.

## Install

```sh
npx nameable <name>
```

Requires Node.js 22 or later. To use it from an AI agent, add `npx -y nameable mcp` as an MCP server, or install the
Claude Code plugin:

```
/plugin marketplace add minanyang/claude-plugins
/plugin install nameable@minanyang
```

## 繁體中文

Nameable 改用 Zod 4.6.7，避開安全公告 [GHSA-mrhx-c7xc-m3w5](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5)：4.6.6 以前的 Zod 在驗證過大的受限集合時可能耗盡記憶體。npm 套件和 Claude Code plugin 的 lockfile 都已換成修正後的版本，檢查名稱的方式沒有其他變動。

需要 Node.js 22 以上。要在 AI agent 裡使用，把 `npx -y nameable mcp` 加成 MCP server，或安裝 Claude Code plugin：

